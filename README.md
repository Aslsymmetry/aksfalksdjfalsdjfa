# 바이브 코딩 랜딩 페이지

`dist/index.html`을 브라우저에서 열면 바로 실행됩니다. 별도 설치나 빌드가 필요하지 않습니다.

- `dist/index.html`: 문구와 페이지 구조
- `dist/styles.css`: 데스크톱 및 모바일 디자인
- `dist/script.js`: 강의 버튼과 안내 창
- `dist/assets/reference.png`: 첨부 이미지에서 중앙 인물과 프로필 사진을 표시하는 원본 자료

참고 이미지 파일은 현재 GitHub에 포함되지 않습니다. 원본 이미지를 `dist/assets/reference.png`에 넣으면 인물, 프로필 사진, 도구 로고가 표시됩니다.

실제 강의 페이지가 준비되면 `dist/script.js`의 `COURSE_URL`에 주소를 입력하세요. 현재 버튼은 신청 링크 준비 중 안내를 표시합니다.

너비 1100px 이하에서는 태블릿 배치가, 760px 이하에서는 세로 배치와 3열 도구 목록이 적용됩니다. 폰트는 Google Fonts에서 불러오며, 인터넷에 연결되지 않았을 때는 시스템 폰트가 적용됩니다.
